# Listicle & Opportunity Search Recipes

Search-query templates for finding "best X tools" roundups and other reproducible backlink
opportunities. Swap `<category>` for the site's niche, `<audience>` for its target user, and
`<competitor>` for a named rival. Run them as web searches.

## Listicles / roundups (highest ROI)

- `best <category> tools`
- `best <category> software`
- `top <category> tools 2026`
- `top <category> apps`
- `<category> tools for <audience>`   (e.g. "for startups", "for agencies", "for developers")
- `best free <category> tools`
- `intitle:"best <category>"`
- `<category> tools list`
- `<category> software roundup`

## Alternatives & comparisons (usually addable)

- `best <competitor> alternatives`
- `<competitor> alternatives`
- `alternatives to <competitor>`
- `<competitor> vs`
- `<category> like <competitor>`

## Resource pages & "awesome" lists

- `<category> resources`
- `<category> tools we recommend`
- `awesome <category>`  (also search GitHub directly for `awesome-<category>` repos)
- `<category> "recommended tools"`
- `intitle:"resources" <category>`
- `inurl:resources <category>`

## Communities (posts + resource threads)

- `<category> site:reddit.com`
- `<competitor> site:reddit.com`
- `site:news.ycombinator.com <category>`
- `<category> tools site:indiehackers.com`

## Competitor presence (gap-finding — pair with data/directories.md)

- `site:<directory-domain> <competitor>`   (is the competitor listed where you're not?)
- `"<competitor>"` review
- `"<competitor>"` -site:<competitor-domain>   (mentions not on their own site)

## Tips

- Prefer results that rank on page 1 and were **updated recently** — those are maintained and
  editable.
- Add a year (`2026`) to surface freshly updated posts.
- Vary the noun: tools / software / apps / platforms / solutions — different posts use different
  words for the same category.
- Always verify a page actually lists tools like the target product before pitching it.
