# Competitor Backlink Mining (free methods)

A competitor's backlink profile is a map of links you can often reproduce. You don't need a paid
tool like Ahrefs to find the reproducible ones — the directories, listicles, communities, and
resource pages that link to a competitor are usually discoverable for free.

## What you're looking for

Only **reproducible** links matter here. Sort competitor links into:
- **Reproducible** — directories, "best X tools" listicles, resource/"awesome" pages, community
  posts, integration/partner pages. You can get these too. ← target these.
- **Not reproducible** — press coverage they earned, their own domains, paid placements, links
  from personal relationships. Note them, don't chase them.

## Free methods to find them

1. **Search for the competitor by name + brand.**
   - `"<competitor>"` — scan who mentions them.
   - `"<competitor>" review` / `"<competitor>" alternative` — reviews and alternatives pages
     (both are usually addable).
   - `intitle:"best" <category>` and check which of those posts list the competitor.

2. **Find "alternatives" and comparison pages.**
   - `<competitor> alternatives`, `<competitor> vs`, `alternatives to <competitor>`.
   - AlternativeTo, SaaSHub, Slant, and Product Hunt "alternatives" tabs list competitors and
     let you add yourself to the same comparison.

3. **Check the obvious directories.** Run the competitor's brand through the directories in
   `data/directories.md` (`site:<directory> <competitor>`). Wherever they're listed and you're
   not, that's a direct gap to close.

4. **Mine communities and resource lists.**
   - `<competitor> site:reddit.com`, `site:news.ycombinator.com <competitor>`.
   - GitHub `awesome-<category>` lists — search the list repos for the competitor; if they're
     in and you fit, open a PR/issue to add yours.
   - Niche resource pages ("tools we recommend", "resources") that link the competitor.

5. **Read the competitor's own footer/integrations/partners pages** — partner and integration
   directories they appear in are often open to you as well.

## Free tools that help (optional)

- **Google Search operators** (above) — the workhorse, no account needed.
- **Directory presence checks** — `site:` searches against `data/directories.md`.
- Some backlink checkers offer a limited free tier (a handful of top links per domain) — enough
  to spot patterns even without a subscription. Use what's available; don't assume paid data.

## Turn it into targets

For each reproducible source found, add it to the plan with: the source URL, the link type
(directory / listicle / community / resource), the effort (submit form / outreach / PR), and
whether you're already there. Then work it like any other opportunity — directories via the
submission playbook, listicles via the outreach playbook.

Don't fabricate a competitor's backlinks — only list sources you actually found in a search.
